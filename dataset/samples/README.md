# Учебные выгрузки дня

Два готовых файла, которыми проверяется загрузка данных и полный проход
сервиса: приём файла → подготовка → расчёт → маршруты → архив. ТЗ требует,
чтобы решение умело брать готовые данные из CSV или JSON, — это они.

| Файл | Формат | Участок | День | Заявок | Чем отличается |
|---|---|---|---|---|---|
| `Восток — выгрузка дня 12.10.2026.csv` | CSV | Восток | 12.10.2026 | 63 | обычный день: подключения и дозаказы, окна 10:00–22:00, аварий мало |
| `Юго-Восток — выгрузка дня 13.10.2026.json` | JSON | Юго-Восток | 13.10.2026 | 58 | день с авариями: треть заявок — глобальные проблемы с круглосуточным окном, утренние пересекающиеся окна, есть GPON |

Оба кладутся в интерфейсе кнопкой своего формата на экране создания расчёта.
JSON интерфейс сводит к той же выгрузке дня и отдаёт программе расчёта тем же
путём, что и CSV, — второго пути к расчёту у него нет.

## Что внутри

Форма — выгрузка нарядов заказчика: шапка «Заявка … Адрес» и строка
«Адрес офиса» внизу, из которой инженеры выезжают. Три колонки добавлены к
исходной выгрузке:

- **Инженер** — ФИО человека, а не «Бригада Соколов»: наш штат участка, тот
  же, что лежит в `dataset/out/<участок>/engineers.json`. Наряд со статусом
  «Не отправлена» стоит без исполнителя — его ещё никому не отдали.
- **Клиент**, **Телефон клиента**, **Лицевой счёт** — кого искать на объекте.
  Настоящая выгрузка контактов не содержит, а интерфейсу инженера без них
  ехать некуда.

Колонка «Инженер» — это то, кто вёл наряд в учётной системе, а не задание
планировщику: расчёт раскладывает заявки по своему штату сам, иначе решать
было бы нечего.

## Откуда взялись значения

Адреса, районы и типы работ взяты из настоящих выгрузок тех же участков
(`dataset/source`): геокодер и сеть дорог на них уже прогреты, поэтому расчёт
по этим файлам считается без выхода в интернет. Номера нарядов, окна,
статусы, технология, инженеры и клиенты — наши; настоящие номера и настоящее
распределение по бригадам в учебные файлы не переносятся.

Собираются заново одинаковыми — генератор считает от зерна, а не разыгрывает:

```bash
python3 dataset/samples/build.py
```
